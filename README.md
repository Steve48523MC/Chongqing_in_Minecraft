# Chongqing in Minecraft (Superflat Project)

*Created by a Chongqing local.*

Welcome to my Minecraft project dedicated to **Chongqing**! 

This project is built on a **Superflat world**, meaning the geographical layout is completely fictionalized. However, **every single place name used in this map is a 100% authentic, real-world location from Chongqing**. 

It is a creative blocky tribute to the "Mountain City", blending the charm of Chongqing's culture and real-world landmarks with the clean canvas of a superflat world.

## 🚧 Current Status

*   **Focus:** The main focus right now is building and testing the **Rail Transit System**. 
*   **Work in Progress:** The city buildings are currently under construction! The skyline will grow gradually as the transit network expands. 

## ✨ Features

*   **100% Vanilla:** Absolutely **no mods or add-ons required**. Everything is built using vanilla mechanics (redstone, rails, or command blocks).
*   **Authentic Place Names:** Explore stations and districts named after real Chongqing locations (e.g., Jiefangbei, Chaotianmen, Hongyadong).
*   **Vanilla Rail Network:** A fully functional rail transit system inspired by the real Chongqing Rail Transit, built entirely within the base game.
*   **Superflat Base:** A purely creative layout built on a flat world, designed to make the transit network and planned city layout stand out clearly.

## 🛠️ Requirements

*   **Minecraft Java Edition** (Version 1.16.5 or later).
*   **No mods needed!** Just load the world and play.

# 我的世界中的重庆 (超平坦项目)

*作者是重庆本地人。*

欢迎来到我的《我的世界》重庆主题项目！

本项目建立在**超平坦世界**之上，这意味着它的地理布局是完全虚构的。但是，**地图中使用的每一个地名，都是来自现实世界中100%真实的重庆地标**。

这是一座向“山城”致敬的方块创意之作，将重庆的文化魅力与真实地标，完美融合在超平坦世界的干净画布中。

## 🚧 当前进度

*   **核心焦点**：目前的主要精力集中在建设和测试**轨道交通系统**上。
*   **在建工程**：城市建筑正在施工中！随着轨道交通网络的延伸，城市天际线也将逐步成型。

## ✨ 特色功能

*   **100% 纯原版**：**无需任何模组 (Mods) 或附加包**。所有内容均使用原版机制（红石、铁轨或命令方块）建造。
*   **真实地名**：探索以真实重庆地标命名的车站和区域（如解放碑、朝天门、洪崖洞）。
*   **原版轨交网络**：完全基于游戏基础机制，还原了重庆轨道交通风格的铁路系统。
*   **超平坦底座**：纯粹的创造模式布局，平坦的地形让轨道交通网络和规划的城市轮廓更加清晰。

# Minecraftの中の重慶 (スーパーフラット・プロジェクト)

*作者は重慶出身です。*

**重慶 (チョンチン)** をテーマにした私のMinecraftプロジェクトへようこそ！

このプロジェクトは**スーパーフラットな世界 (Superflat world)** に建設されているため、地理的なレイアウトは完全に架空のものです。しかし、**このマップで使用されている地名は、すべて現実世界の重慶に実在する本物の場所です**。

「山の都（マウンテン・シティ）」へのオマージュとして、重慶の文化と実在のランドマークの魅力を、スーパーフラットのきれいなキャンバスに融合させたクリエイティブな作品です。

## 🚧 現在の進捗

*   **フォーカス:** 現在は**鉄道輸送システム**の建設とテストに注力しています。
*   **進行中の作業:** 街の建物は現在建設中です！鉄道網の拡大に合わせて、街並みも少しずつ形になっていきます。

## ✨ 特徴

*   **100%バニラ（純正版）:** **MODやアドオンは一切不要**です。すべてバニラのメカニズム（レッドストーン、レール、コマンドブロック）のみで建設されています。
*   **本物の地名:** 重慶の実在の場所（解放碑、朝天門、洪崖洞など）にちなんで名付けられた駅や地区を探索できます。
*   **バニラ鉄道網:** 実際の重慶軌道交通にインスパイアされた、基本機能だけで動作する鉄道システム。
*   **スーパーフラットのベース:** 完全にフラットな世界に構築されたクリエイティブなレイアウトで、鉄道網と計画中の都市計画がはっきりと際立ちます。

## 🛠️ 動作環境

*   **Minecraft Java Edition** (1.16.5 以降)。
*   **MODは不要です！** ワールドをロードするだけでプレイできます。
